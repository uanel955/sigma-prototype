# Design

## Visuel retning
- Lys creme/off-white base med varm neutral kontrast.
- Premium skandinavisk klinikstemning, blød men professionel.
- Produktflade med tydeligt hierarki, få valg og store CTA'er.

## Farvesystem
- Baggrund: varm off-white.
- Overflader: lysere kortflader med subtil kant og skygge.
- Primær accent: dæmpet blomme/rosé for Aurora Hudklinik.
- Sekundær accent: oliven og bronzetone til tags og badges.
- Tekst: varm kulsort neutral, ikke ren sort.

## Typografi
- Native systemfont til al UI for et mere roligt produktudtryk.
- Ingen displayfont i appfladen.
- Små labels holdes kompakte og læsbare, CTA'er tydelige og brede.

## Komponenter
- Kort med blød kant og 8 px radius.
- Store primære knapper, diskrete tekstknapper og enkle valgknapper.
- Bottom navigation, statusbadges, toggles og korte admin-paneler.

## Layout
- Mobil-first artboard med reel scroll inde i telefonfladen.
- Desktop prototype-stage med to device-frames side om side.
- Konsistente afstande, tre brugerfaner og tydelig opdeling mellem Bruger og Admin.

## Motion
- Korte 160-220 ms overgange til skærmskift, valg og hover/fokus.
- Ingen dekorativ bevægelse uden UI-formål.
